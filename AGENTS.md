# AGENTS.md: вход для агентов, продолжающих работу

## Что это за проект

Собственный кооперативный мультиплеер для Noita (2–4 игрока, полное прохождение, многодневные
забеги с перезаходами). Он заменяет Entangled Worlds (EW). Аналитический пакет подготовлен;
есть каркас сервера забега на Rust (`protocol/`, `server/`, `agent/`, этап 2), проверенный
тестами без игры. Lua-мода и игровой синхронизации ещё нет. Есть также `tools/unpack_wak.py`.

Язык общения и основных документов: русский. Технические отчёты `docs/research/` — английские.
Идентификаторы, имена в коде и коммиты пишутся на английском.

## Порядок чтения

1. `docs/REQUIREMENTS.md`: требования `R*`. Это источник истины о том, *что* нужно.
2. `docs/DECISIONS.md`: принятые решения `D*`. Их не пересматривают без явного согласия
   пользователя.
3. `docs/OPEN_QUESTIONS.md` и `docs/questionnaire/`: реестр открытых вопросов `Q*` и полный
   опросник. Перед проектированием подсистемы проверьте, не блокирует ли её вопрос с
   приоритетом A/B. Ответы пользователя читайте из `docs/questionnaire/ANSWER_SHEET.md`
   (`?` = не отвечено, `рек` = принять рекомендацию, `ВСЕ_ОСТАЛЬНЫЕ` задаёт режим для
   пропущенных). Принятое по `рек`/умолчанию записывайте в `DECISIONS.md` как `[ВРЕМЕННО]`,
   ответ пользователя — как обычное `Dn`, и перенесите вопрос в «Закрытые».
4. `docs/EVIDENCE.md`: приоритет источников, исправления ранних выводов, границы достоверности.
5. `docs/ARCHITECTURE.md` и `docs/SYNC_CONTRACTS.md`: предложение архитектуры и инварианты
   хранения/протокола. Это не принятые решения о стеке и не готовая реализация.
6. `docs/LOOT_CATALOG.md`, `docs/ACCEPTANCE.md`: предметные правила и проверяемые сценарии.
7. `docs/ROADMAP.md`: этапы, текущий статус, следующий шаг.
8. `docs/research/`: исследования с привязкой к исходникам:
   - `ew_architecture.md`, `ew_problems.md`: EW и наблюдаемые отказы;
   - `noita_capabilities.md`: ранний обзор, уточнённый в `EVIDENCE.md`;
   - `vanilla_pickups.md`: золото, орбы, сердца, сундуки, боссы, перки, секреты, NG+;
   - `vanilla_world_and_saves.md`: генерация, форматы сейвов, игрок, смерть, касты.

## Внешние ресурсы на машине пользователя

| Путь | Что там |
|---|---|
| `/data/Games/steamapps/common/Noita` | Установка игры. `tools_modding/lua_api_documentation.txt`, `component_documentation.txt`, `data/data.wak` (архив ванильных скриптов), `mods/` |
| `/data/Games/steamapps/common/Noita/_version_hash.txt` | Хеш сборки игры, под которую идёт разработка (ветка `master`) |
| `~/noita_entangled_worlds_fix` | Форк EW с фиксами пользователя. Только для чтения и изучения, код **не копировать** (D7) |
| `~/noita_entangled_worlds` | Вторая копия EW с расследованием сердец (`docs/heart_pickup_investigation.md`) |
| `/data/Development/Projects/noita-switcher` | Утилита пользователя для профилей сейвов Noita (соло/кооп) |
| `~/noita_cartographer` | Мод карты, для которого пользователь делал синхронизацию через EW |

Сейвы Noita под Proton лежат в префиксе Steam (`compatdata/881100/pfx/.../Nolla_Games_Noita/save00`).
Точный путь и структура описаны в `docs/research/vanilla_world_and_saves.md`. **Никогда не
изменяйте сейвы и установку игры без явной просьбы**: у пользователя идут реальные забеги.
Для чтения ванильных скриптов запускайте `python3 tools/unpack_wak.py` (14 745 файлов в
игнорируемом `.cache/noita-data/`). Не коммитьте файлы игры или сохранения.

## Жёсткие правила проекта

- Код EW не копировать и не переписывать построчно (D7). Идеи и знания о движке брать можно, со
  ссылкой на источник в документе.
- Хост авторитетен (D3). Любой механизм, где клиент может перезаписать состояние хоста своим
  локальным сейвом, считается ошибкой.
- Восстановление забега и новый забег — разные пути кода (R6.4).
- Дискретные изменения общего состояния (подборы, смерть, покупка) имеют уникальный ID и
  применяются идемпотентно. Непрерывная симуляция передаётся версионированными снимками.
  Нельзя ждать финального снимка от уже упавшей игры; используйте последнюю подтверждённую
  версию и fencing эпохи авторитета (`SYNC_CONTRACTS.md`).
- Каждая сущность в каждый момент имеет ровно одного авторитета. Авторитет не передаётся игроку,
  чья игра не запущена (R6.6).
- Новые решения записывайте в `docs/DECISIONS.md`, новые вопросы в `docs/OPEN_QUESTIONS.md`, а
  статус в `docs/ROADMAP.md`, в том же изменении, где они появились.
- Проверять гипотезы о движке через `lua_api_documentation.txt` и ванильные скрипты из
  `data.wak`, а не по памяти. Непроверенное помечайте `[INFERENCE]`.
- Сервер не принимает клиентский `wallet.money` как истину. Доход и траты — разные транзакции;
  порошок собирается нативно, не через `gold_pickup.lua`. N-кратный лут не размножает доход.
- Не копируйте бандл NoitaPatcher из EW. Независимый upstream, provenance, лицензия и ABI
  проверяются до подключения. «MIT» пока не подтверждена.
- Не выдавайте прототипы, схемы и статический анализ за игровую проверку. Особые риски:
  полная геометрия физических тел, native orb accounting, порошок, сложные касты.

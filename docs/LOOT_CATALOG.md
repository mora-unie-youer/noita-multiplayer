# Каталог наград для согласования

Подтверждён общий принцип D14–D15: каждому хватает предметных наград; случайные награды могут
отличаться, чужие исходные экземпляры брать нельзя. Ниже **кандидаты**, не дополнительный набор
уже принятых решений. Точные ванильные пути и строки: `research/vanilla_pickups.md` §5–8.

## Уникальные места и наборы (Q25)

| Место / условие | Что положено каждому | Особое правило |
|---|---|---|
| Дерево / комната Окарины | Инструмент и полный исходный набор нот | В ванилле по две копии каждой ноты вне инструмента; нельзя ещё раз удвоить этот набор |
| Конец Башни | Собственный выбор одного из трёх великих жезлов | Не 3N доступных жезлов: взятый выбор удаляет только две свои альтернативы |
| Комната жезла | Экспериментальный жезл №3 | Сгенерировать и сохранить характеристики один раз; RNG зависит от кадров |
| Хижины у озера / бункеры | Экспериментальные жезлы №2/№1, цвета/условные заклинания | Фиксированные наборы карточек сохраняются, флаги открытия общие |
| Мясной босс | Экспериментальный жезл №4 | Смерть босса и сердце/прочие эффекты не переигрываются N раз |
| Сауна в Hiisi Base | Vasta/Vihta | Сохранять тип и постоянное заклинание |
| Приёмники масла, воды, пара | Ruusu, Valtikka, Kiekurakeppi | Условие загадки активируется один раз; награды отдельно на слоты |
| Загадка лаборатории Vault | Arpaluu или Varpuluuta | Вариант и свойства фиксируются до выдачи, не переролливаются после входа |
| Рыбное жертвоприношение | Челюстной жезл Leukaluu | Один fish-rain event; размножается финальная награда, не дождь |
| Кузница | Челюсть+Кантеле, FISH, починка портала/жезла | Потребление входных предметов и выходы — одна транзакция; политика размножения крафта не решена |
| Радуга на озере | RAINBOW_TRAIL | Конкретное заклинание, не случайная карта |
| Весы солнц | BLACK_HOLE_GIGA | Профильные флаги не должны убрать награду у другого игрока |
| Лунная комната | MOON_RADAR | Специальный перк не удаляет персональные предложения Святой горы |
| Робот-босс | Spatial Awareness (MAP) | Это перк, не жезл; выдавать как персональную награду |
| Орбы | Награда-открытие заклинания либо сердце | Зависит от профиля; общий счётчик, личное открытие и HP — разные слои (Q22/Q31) |
| Стальной/светлый/тёмный/тьмы сундуки | Гарантированные секретные наборы | Ключ и активация общие; каждый получает положенные заклинания |
| Верхняя луна | DESTRUCTION; при дополнительных условиях touch-набор | Эссенции/алтарь и превращение мира не размножаются |
| Награды вершины/секретного маркера | NUKE_GIGA, BOMB_HOLY_GIGA, DIVIDE_10 или AIR_BULLET | Сохранять условие награды и фиксированный ID заклинания |
| Магазины небес/ада | Случайные заклинания высокого уровня | Предлагается персональный магазин по аналогии с D13; отдельно подтвердить |

`wand_petri.xml` найден как определение, но активное фиксированное место спавна не установлено.
Не обещать его как существующий секрет. Обычные жезлы на полу и у мобов пока предлагаются общими
в одном экземпляре; пользователь ещё не подтвердил границу «обычный / особый» (Q25).

## Боссы и смешанные награды

Полная таблица боссов и callbacks — `research/vanilla_pickups.md` §5.2.
Подтверждённая политика D14 относится к **предметным наградам**. Разнести слои:

1. Смерть, уничтожение частей, открытие прогресса/перехода мира — общий результат один раз.
2. Карточки/жезлы/специальные перки — персональная награда на слот.
3. Золото — один физический дроп, общий доход D4, без N-кратного повторного дохода.
4. Сердце/орб — общий эффект D6/R2, без повторного усиления от каждой персональной партии.
5. Ключ алхимика, Сампо, сундуки на теле босса, эссенции и квестовые объекты — отдельные правила
   Q15/Q28, нельзя объявить их обычным жезлом и размножить вместе со всем остальным.

## Перки, которым недостаточно «личного спавна» (Q13)

| Категория | Примеры | Что требуется |
|---|---|---|
| Учёт личного прогресса | Счётчики стеков, deck cursor, рероллы, Lottery, Extra Perk/Shop Item | Хранение на слот, не в глобальных переменных. Удаление альтернатив ограничено своим набором |
| Личный эффект через Globals | Stronger Hearts, Shield, Attract Gold, трансформации | Перенести счётчики в состояние игрока, включая читателей этих значений |
| Эффект на общий дроп | Gold Is Forever, Trick Blood Money, No Wand Editing, Exploding Gold | Выбрать: командный эффект или по перкам убившего. Один канонический результат дропа |
| Эффект на существующие вещи/мир | Unlimited Spells, No More Shuffle, Peace With Gods, More Love/Hatred, дружба крыс | Для каждого выбрать scope и владельцев вклада. Удаление перка одного игрока не снимает вклад другого |
| Null room / снятие перков | Пересоздание всех взятых перков | Ваниль читает глобальные флаги; иначе отдаст одному игроку сумму перков всей команды |

Extra Money применяется **на подобравшем самородок** (×2 за стек), а не при создании дропа.
Не путать это с trick-kill gold multiplier. Как сочетать его с общим доходом — Q27.

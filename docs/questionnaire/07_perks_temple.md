# 07. Перки и Святая гора

## Q13 (B). Перки с глобальным эффектом

**Контекст.** D5: перки личные. Но ванильные перки пишут **общее** состояние мира (поля
`WorldStateComponent`, Globals, run-флаги, `research/vanilla_pickups.md` §8). Отдельно: сам учёт
перков (счётчики стеков, колода, цена реролла) в ванилле глобальный и должен стать личным,
иначе перк игрока A удаляет предложения игрока B. Это решается безусловно (обязательная часть
реализации), вопрос только про **эффект**.

Для каждого перка выберите:
- **T (team)**: эффект действует на всю команду, как в ванилле (при взятии одним игроком).
- **O (owner)**: эффект только у владельца или только на его добыче/убийствах.
- **X** — исключить из колоды (бан).

| Перк | Что делает в ванилле | Рек. |
|---|---|---|
| `GOLD_IS_FOREVER` | золото с убитых врагов и сундуков не исчезает (мир) | T |
| `TRICK_BLOOD_MONEY` | трик-убийства дают кровавые деньги | T |
| `EXPLODING_GOLD` | золото взрывается (взрыв приписан первому игроку) | T (и приписывать взрыв владельцу) |
| `HEARTS_MORE_EXTRA_HP` | множитель эффекта сердец (Globals) | O (личный множитель, Q12d) |
| `NO_WAND_EDITING` | +20% шанс кровавых денег при убийстве | T |
| `UNLIMITED_SPELLS` | почти бесконечные заклинания | O (если технически возможно ограничить на владельца; иначе T или X) |
| `NO_MORE_SHUFFLE` | отключает перемешивание на **всех** жезлах мира, включая будущие | O (только жезлы владельца), иначе T/X |
| `SHIELD` | щит; размер зависит от числа взятий (Globals) | O |
| `ATTRACT_ITEMS` | притягивает золото; радиус общий | O |
| `REVENGE_RATS`, `PLAGUE_RATS`, `VOMIT_RATS` | крысы дружественны всем игрокам | T |
| `GENOME_MORE_HATRED` / `GENOME_MORE_LOVE` | меняют отношения всех фракций (мир) | T |
| `PEACE_WITH_GODS` | Стиви не появляется, шаманы дружелюбны для всех | T |
| `EXTRA_PERK`, `PERKS_LOTTERY`, `EXTRA_SHOP_ITEM`, `GAMBLE` | число перков/товаров/шанс уничтожения | O (в личной Святой горе) |
| Перки-трансформации (`CORDYCEPS`, `MOLD`, `FUNGAL_DISEASE`, призраки, `LUKKI_MINION`, …) | счётчики (Globals) считают всех игроков суммарно | O (счётчики личные) |
| Нулевая комната (`null_room`), снятие всех перков | пересоздаёт **все** перки по общим флагам | O (только перки того, кто активировал) |

**Общий вопрос.** Если T-перк (например, `PEACE_WITH_GODS`) выбрал один игрок, команда видит
изменение мира без участия остальных. Это допустимо? A) да (кооператив, общий эффект);
B) такие перки в колоде оставить только для случаев, где T безопасен (остальное X).

**Перки, которые не работали в EW** (`docs/perks_that_dont_work_properly.md` EW):
`ABILITY_ACTIONS_MATERIALIZED`, `RESPAWN`, `TELEKINESIS`, `SAVING_GRACE`, `INVISIBILITY`
(пятна не синхронизируются), `CORDYCEPS`, `HOMUNCULUS`. Что делать с ними?
- A) Поддерживать по мере сил, без бана (рек. для `RESPAWN`/`SAVING_GRACE`, см. Q54).
- B) Исключить из колоды в первых версиях (удаление из пула меняет вероятности остальных).
- C) Оставить как есть и пометить «может работать неверно».

**Реролл перков.** Цена возрастающая и общая в ванилле. A) личная цена на игрока (рек.);
B) общая.

**Рекомендация:** таблица по колонке «Рек.», общий вопрос A, перки EW — A.

## Q32 (B). Святая гора: обвал, гнев, воровство

**Контекст.** Магазин, перки и сердце личные (D5/D13/Q12b), но здание и обвал — общий мир.

**(a) Обвал.** Ваниль: вход обваливается, когда игрок выходит (`workshop_exit.lua`).
- A) Как ваниль: первый вышедший обрушивает гору, остальные, кто ещё внутри, теряют доступ (можно
  вернуться, раскопав [INFERENCE]).
- B) Не обваливается никогда.
- C) Обваливается, когда вышли **все онлайн-игроки** (рек.). Офлайн-игрок, не заходивший в гору,
  получит свои персональные перки/магазин позже по правилу ниже.
- D) Обваливается, когда вышли все слоты, для которых гора уже посещена и «закрыта» (взяты/пропущены
  перки). Опасность: вечное ожидание, если игрок ушёл навсегда.

**(b) Персональные товары и перки для того, кто не зашёл вовремя.** A) остаются в горе и ждут
(она остаётся доступной, пока игрок не получит их или хост не закроет принудительно);
B) при обвале теряются (как для игрока, проскочившего гору в ванилле); C) переносятся в
следующую гору (накапливаются).

**(c) Воровство и гнев Стиви.** Ваниль: украсть товар из магазина — гнев и появление Стиви.
A) Любая кража любым игроком гневит всех (мир); B) только вора (его личный Стиви).
Рек.: A.

**(d) Спелл-рефрешер и сердце горы.** Персональные (каждому по штуке): да (рек.) / общие.

**(e) Ограничения жезлов** (редактирование жезлов в Святой горе). Личные: да (рек.).

**Рекомендация:** (a) C, (b) A, (c) A, (d) да, (e) да.
